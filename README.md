# 📈 Smart Investment Intelligence System

A data-driven financial decision support system designed to simplify stock market analysis and help users make more informed investment decisions.

The system processes stock market data, analyzes investment performance and risk, predicts future stock prices, provides interactive visualizations, and sends automated email alerts for stocks with a **Buy** recommendation.

---

## 🚀 Overview

Investors often have to analyze large amounts of stock market data from multiple sources. Manually comparing stocks, calculating returns, monitoring risk, and tracking future trends can be time-consuming and error-prone.

The **Smart Investment Intelligence System** automates these tasks by combining data analysis, prediction, visualization, and automated alerts into a single workflow.

### Key capabilities

- 📊 Stock market data processing and analysis
- 📈 ROI and performance analysis
- ⚠️ Risk and volatility analysis
- 🔮 Next-day stock price prediction
- 💡 Buy recommendations
- 📊 Interactive Power BI dashboard
- 🌐 Streamlit-based web interface
- 📧 Automated email alerts for Buy recommendations
